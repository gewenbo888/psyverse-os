# PsyVerse · 可验证智能互联网

The experiential interface site for PsyVerse — a living universe of verifiable intelligence. A bilingual (EN / 中文) AAA-tech presentation of blockchain state, recursive proofs, AI agents, and the network topology of Psy Protocol, framed as a single coordinated computational substrate.

The site renders a fixed full-viewport canvas of drifting neural-particle nodes with subtle pulsing connections behind glassmorphism content layers, plus several inline-SVG visualizations: a six-node animated state-transition flow (state root → tx batch → WASM execution → circuit → π proof → next root, with flowing dashed edges and ambient particles); a network-topology graph (a coordinator at the centre, four realms, validator clusters, prover squares, relayer triangles, with animated dashed connection lines on a soft grid); a five-cell civilization timeline (neurons → GPU → transformer → verifiable state → PsyVerse network civilization); a two-pane proof-layer panel with the recursion equation laid out in mono with mint/cyan/violet syntax accents; a six-card AI explainer module covering change feed, risk read, whale tracking, anomaly detection, proof verification status, and context-attached summaries; and a developer ecosystem panel with switchable code samples for the SDK, JSON-RPC API, WASM runtime, AI agent framework, and explorer GraphQL — bilingual code, with full mono syntax highlighting (keyword / function / string / type / comment / number colors).

The hero's four counters (TPS, proofs/hr, contracts alive, AI agents online) are explicitly labeled as illustrative — the section header carries `MAINNET · REALM 0 · LIVE (ILLUSTRATIVE)` and a mono caption underneath the counters reads `// counters above animate on a synthetic seed for demo purposes — not pinned to live mainnet RPC`. This is deliberate honesty about real-vs-simulated data: the visualizations are architectural schematics, not a real-time mainnet feed.

The brand surface is the canonical Psy palette: black `#0a0a0c` background, mint `#61f5b3` primary, electric blue and violet accents, soft mint glow on the seal, no aggressive glow on CTAs. Cabin Condensed for display, Inter for body, JetBrains Mono for technical labels and counters, Noto Sans SC for Chinese. The actual psi-glyph.svg from the official Psy Protocol site is used in the topbar seal and as the favicon — the same brand asset shipping at psy.psyverse.fun and zk-civilization.psyverse.fun.

## Stack

Plain HTML, CSS, vanilla JS. Canvas 2D for the neural particle background. Inline SVG for the state-transition diagram and topology graph. Cabin Condensed + Inter + JetBrains Mono + Noto Sans SC. No build step, no framework — fast to ship, fast to load, fully responsive.
